# Контрольная работа №5 — React Shop

Тема: «Компонентная frontend-разработка на React или Vue с подготовкой проекта к подключению backend API».

## Описание

Проект представляет собой SPA-версию учебного интернет-магазина на React + Vite.

Предметная область перенесена из предыдущих контрольных работ (КР №1–КР №4).

## Практическая работа №19

Выполнено:

- создан проект `kr5-react-shop` через Vite;
- проект запускается через `npm run dev`;
- очищен демонстрационный шаблон Vite;
- подготовлена структура `src/components`, `src/data`;
- создан файл `src/data/products.js` (10 товаров);
- создан компонент `Header`;
- создан компонент `ProductCard`;
- создан компонент `ProductList`;
- товары выводятся через `map()` с `key={product.id}`;
- данные передаются через props;
- добавлены базовые стили.

## Структура проекта

- **public/** — статические файлы
- **src/** — исходный код приложения
    - **src/assets/** — изображения и иконки
    - **src/components/** — React-компоненты
        - `Header.jsx` — шапка сайта
        - `ProductCard.jsx` — карточка товара
        - `ProductList.jsx` — список товаров
    - **src/data/** — данные товаров
        - `products.js` — массив из 10 товаров
    - `App.jsx` — главный компонент
    - `App.css` — стили приложения
    - `index.css` — базовые стили
    - `main.jsx` — точка входа React
- `index.html` — HTML-страница
- `package.json` — зависимости проекта
- `vite.config.js` — конфигурация Vite
- `eslint.config.js` — настройки ESLint
- `README.md` — описание проекта
- `.gitignore` — исключения для Git

## Практическая работа №22

Тема: «React Router: страницы SPA, навигация, параметры маршрута и страница 404».

### Выполнено:
- установлен `react-router-dom`;
- приложение обёрнуто в `BrowserRouter` (с `basename="/kr5-react-shop"`);
- настроены маршруты через `Routes` и `Route`;
- создана главная страница `HomePage`;
- каталог перенесён на маршрут `/catalog`;
- создана страница товара `ProductPage`;
- реализован динамический маршрут `/catalog/:productId`;
- параметр товара получен через `useParams`;
- обработана ситуация, когда товар не найден;
- создана страница заявки `/order`;
- создана страница корзины `/cart`;
- создана страница 404 `NotFoundPage`;
- навигация реализована через `NavLink`;
- карточки товаров содержат ссылки на подробную страницу;
- обновлены стили навигации и страниц.

### Маршруты приложения
| Маршрут | Компонент | Назначение |
|---|---|---|
| `/` | `HomePage` | главная страница |
| `/catalog` | `CatalogPage` | каталог товаров |
| `/catalog/:productId` | `ProductPage` | подробная страница товара |
| `/order` | `OrderPage` | форма заявки |
| `/cart` | `CartPage` | корзина |
| `*` | `NotFoundPage` | страница 404 |
