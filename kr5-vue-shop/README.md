## Практическая работа №25 (Vue-вариант)

Тема: «Vue 3 + Vite: старт альтернативной SPA-версии интернет-магазина».

### Выполнено:
- создан проект `kr5-vue-shop` через Vite;
- очищен демонстрационный шаблон;
- создан файл `src/data/products.js` с массивом товаров;
- реализован каталог товаров в `App.vue` с использованием `<script setup>`;
- использованы реактивные значения `ref` (поиск, категория, сортировка, счетчик);
- использовано вычисляемое значение `computed` (`visibleProducts`);
- использованы директивы `v-model` для поиска, фильтра и сортировки;
- использованы директивы `v-if` и `v-else` для пустого состояния;
- использована директива `v-for` для вывода карточек товаров;
- использован атрибут `:key="product.id"` для корректного обновления списка;
- использованы сокращения `:` (v-bind) и `@` (v-on);
- реализован поиск по названию;
- реализована фильтрация по категории;
- реализована сортировка по цене и названию;
- реализовано пустое состояние каталога;
- реализован базовый счётчик добавленных товаров;
- обновлены стили (шапка, кнопки, сетка карточек).

### Связь с КР №5
Проект является альтернативной Vue-реализацией SPA-интернет-магазина. В дальнейшем планируется разбиение на компоненты, передача данных через `props`, события через `emit` и подключение Vue Router.
